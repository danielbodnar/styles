# DESIGN.md reference library

Twenty-six curated examples from `VoltAgent/awesome-design-md` (MIT). Each is a
complete, spec-conformant DESIGN.md: YAML frontmatter carrying `colors`,
`typography`, `spacing`, `rounded`, and `components`, followed by Markdown
sections covering Overview, Colors, Typography, Layout, Components, Shapes,
Elevation and Depth, Responsive Behavior, Do's and Don'ts, Iteration Guide, and
Known Gaps.

**Read this index first. Load at most one or two full files.** Each is roughly
30 to 50 KB, which is 8,000 to 13,000 tokens.

## How to use these

Three valid uses, in descending order of preference:

1. **As a schema template.** Copy the structure, replace every value with the
   project's own. This is the default.
2. **As a starting point for a stated aesthetic.** When the person names a
   feeling ("warm and editorial", "dense technical dark"), open the closest
   match and adapt it.
3. **As a vocabulary source.** Read the Do's and Don'ts and Iteration Guide
   sections to learn how design intent gets written down precisely.

These are community analyses of public brand surfaces, not licensed brand
assets. Several use deliberately altered names in prose for that reason. Use
them to learn structure and calibrate proportion. Do not ship a clone of
another company's identity.

## Selecting by intent

| Intent | Candidates |
|---|---|
| Warm, humanist, editorial | `claude`, `airbnb`, `warp` |
| Near-black product surface, dense and technical | `linear.app`, `vercel`, `sentry`, `mintlify` |
| Developer platform, high contrast | `supabase`, `cursor`, `resend`, `raycast` |
| Financial or infrastructure trust | `stripe`, `ibm` |
| Enterprise, systematic, token-disciplined | `ibm`, `shopify` |
| Stark monochrome, oversized type | `uber`, `nike`, `figma`, `wired` |
| Photography-led, gallery pacing | `apple`, `airbnb` |
| Playful, saturated, consumer | `posthog`, `pinterest`, `notion` |
| Retro period study | `dell-1996`, `nintendo-2001` |
| Luxury and automotive | `ferrari` |
| Console and entertainment | `playstation` |
